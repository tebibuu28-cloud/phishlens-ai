# 🛡️ PhishLens AI

An AI-powered phishing email detection platform that helps users analyze suspicious emails, detect social engineering attacks, and understand security risks instantly.

## Features

- 🔍 Email phishing analysis
- 📊 Risk scoring (0-100)
- 🚨 Threat indicators
- 🔐 Secure authentication
- 📁 Saved analysis history
- 📈 Security dashboard
- 📄 Export scan reports

## Tech Stack

Frontend:
- React
- TypeScript
- Vite
- Tailwind CSS

Backend:
- Supabase Authentication
- PostgreSQL Database

Deployment:
- Vercel
